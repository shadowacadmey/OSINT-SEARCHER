## 🧪 دقت نتایج (مهم بخوانید)

| وضعیت | معنی |
|---|---|
| `[+] FOUND` | پروفایل با اطمینان بالا وجود دارد |
| (چاپ نمی‌شود) | یوزرنیم در آن سایت آزاد است |
| `[!] UNVERIFIABLE` | سایت پاسخ قابل اتکایی نداد (بلاک/چالش/کندی) — نه موجود است نه ناموجود |

- **اینستاگرام، ردیت، مدیوم، پاتریون، بهنس و فیسبوک** درخواست‌های IP دیتاسنتر/VPN را محدود می‌کنند؛ از IP خانگی نتیجه بهتری می‌گیرید.
- **Pinterest و Twitch** به IPهای پرچم‌دار به‌جای 404 صفحه جاوااسکریپت می‌دهند که ممکن است مثبت کاذب بسازد؛ از IP تمیز درست کار می‌کنند.
- **Spotify** صفحاتش کاملاً با جاوااسکریپت رندر می‌شوند و از سمت سرور قابل تشخیص نیستند؛ بنابراین همیشه «قابل تأیید نیست» گزارش می‌شود.
- **پلتفرم‌های ایرانی** (آپارات، ایتا، روبیکا، بله، ...) دسترسی از خارج از ایران را محدود می‌کنند و فقط از داخل ایران (یا IP ایران) جواب می‌دهند.
- **فیسبوک** برای بازدیدکننده‌ی لاگین‌نشده محدودیت دارد؛ اگر پروفایل خصوصی باشد یا به صفحه لاگین پرش کند، «قابل تأیید نیست» گزارش می‌شود.

## 🛠️ باگ‌های رفع‌شده نسبت به نسخه اول

1. **کرش هنگام ذخیره گزارش:** کاراکتر فارسی `ا` قبل از `60` (`"-" * ا60`) باعث `NameError` در لحظه‌ی نوشتن فایل گزارش می‌شد.
2. **منطق برعکس تلگرام:** رشته‌ی «If you have Telegram, you can contact» فقط در صفحه‌ی یوزرنیم‌های *آزاد* ظاهر می‌شود؛ در نسخه قبلی پروفایل‌های موجود را «یافت نشد» و ناموجودها را «پیدا شد» گزارش می‌کرد. مارکر صحیح HTML جایگزین شد.
3. **تیک‌تاک کاملاً خراب بود:** متن «Couldn't find this account» در صفحه‌ی موجود و ناموجود *هر دو* وجود دارد و همه چیز را «یافت نشد» می‌کرد. مارکر صحیح `"statusCode":10221` (فقط در صفحه ناموجود) جایگزین شد.
4. **استیم:** متن خطای واقعی `The specified profile could not be found` است؛ رشته‌ی قبلی هیچ‌وقت match نمی‌شد و همه چیز «پیدا شد» می‌شد.
5. **ویرگول:** indicatorهای «۴۰۴» و «یافت نشد» داخل صفحه‌ی پروفایل‌های *واقعی* هم بودند و پروفایل‌های موجود را حذف می‌کردند؛ حالا از کد وضعیت HTTP 404 استفاده می‌شود.
6. **خطای 403/429 دیگر «پیدا شده» حساب نمی‌شود:** بلاک و محدودیت نرخ، دلیل وجود اکانت نیست.
7. **صفحات چالش ضدربات** (Cloudflare «Just a moment»، چالش SlideShare) و **ری‌دایرکت‌های لاگین** به‌عنوان «قابل تأیید نیست» تشخیص داده می‌شوند.
8. **Vimeo:** وضعیت 410 (پروفایل حذف‌شده) هم به «ناموجود» اضافه شد.
9. **اینستاگرام:** مارکر «Sorry, this page isn't available.» اضافه شد.
10. کاراکترهای HTML خراب (`&gt;`، `&amp;`) در کد اصلاح شدند.
