## 🧠 تشخیص خودکار نوع ورودی

| ورودی شما | حالت | چک خودکار |

| شماره تلفن | `PHONE` | ✅ اکانت **واتساپ** (با اسم صاحب شماره!) |

| نام / نام کسب‌وکار | `NAME` | داک‌های سایت‌های ایرانی + **سایت‌های دولتی ثبت کسب‌وکار** |

## 📋 ۲۳ سایت/پیام‌رسان بررسی‌شده

**پیام‌رسان‌ها:** تلگرام، ایتا، روبیکا، بله، سروش‌پلاس، گپ، آی‌گپ
**ویدیو و بلاگ:** آپارات، ویرگول، بلاگفا، میهن‌بلاگ، بلاگ.آی‌آر، پرشین‌بلاگ، بلاگ‌اسکای
**شبکه اجتماعی و بازار:** فیس‌نما، لنزور، کافه‌بازار، باسلام، شنوتو، نماوا، زومیت
**کاریابی و فریلنسری:** جاب‌یاب، پونیشا
**آگهی و فروشگاه کسب‌وکار:** شیپور (`sheypoor.com/shop/نام-فروشگاه`)

## 🏛️ بخش کسب‌وکار و سایت‌های دولتی

چون سایت‌های دولتی ایران فرم و کپچا دارند، ابزار **داک‌های آماده‌ی گوگل** می‌سازد که اطلاعات ثبت‌شده را از دل همین سایت‌ها بیرون می‌کشد:

- 🏅 **نماد اعتماد الکترونیکی (ENAMAD)** — نام صاحب کسب‌وکار، شناسه ملی
- 🏛️ **سامانه نشانه ملی (Samandehi)** — ثبت کسب‌وکارهای مجازی
- 📰 **روزنامه رسمی (rrk.ir)** — ثبت شرکت‌ها، برندها، مدیران و سهام‌داران
- 🏢 **سامانه ثبت شرکت‌ها (ssaa.ir)** — اطلاعات شرکت‌های ثبت‌شده
- 🔎 داک ترکیبی: `"نام" (شماره ثبت OR شناسه ملی OR کد اقتصادی)`
- 🛒 **آگهی‌های کسب‌وکار در دیوار و شیپور:** داک‌های آماده‌ی `site:divar.ir` و `site:sheypoor.com` (فروشگاه اختصاصی شیپور به‌صورت خودکار هم چک می‌شود؛ دیوار پروفایل عمومی با یوزرنیم ندارد و فقط از طریق داک جست‌وجو می‌شود)

این لینک‌ها در حالت NAME چاپ می‌شوند و در گزارش همه‌ی حالت‌ها هم ذخیره می‌شوند.

## 🔧 حالت PROBE (مهم!)

خیلی از سایت‌های ایرانی دسترسی از **خارج از ایران** را بلاک می‌کنند. اگر روی سرور خارجی/VPN اجرا کنید آن سایت‌ها «UNVERIFIABLE» می‌شوند.

```bash
python3 iran_osint.py --probe
```

جدولی می‌دهد که نشان می‌دهد کدام سایت از اینترنت شما جواب می‌دهد:
- همه FOUND/not-fd → ابزار آماده است ✅
- UNKNWN → IP شما بلاک است؛ با اینترنت خانگی داخل ایران اجرا کنید
